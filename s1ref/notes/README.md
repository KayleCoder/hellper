### ⚠ 第 4 條的結論已推翻

本檔原先建議「戰爭手／戰爭棒 改成台版音譯的威漢德／沃貝特」。**這是錯的，現已反向定案。**

那三個姓氏是一組：**워핸드＝War Hand（戰爭手）／워텅＝War Tongue（戰爭舌）／
워배트＝War Bat（戰爭棒）**，對應手、舌、男性生殖器。台版把三個全部音譯成
威漢德／威東格／沃貝特，全季 **0 次**譯出本義，所以單看第一季發現不了這是一組。

第三季**一律改用意譯**：修賓·戰爭手 / 裘納納·戰爭舌 / 香·戰爭棒。
（簡體：修宾·战争手 / 裘纳纳·战争舌 / 香·战争棒）

另：四位大天使＝**L / O / V / E**，合起來拼成 LOVE，寫拉丁字母不音譯
（本檔第168話裡 E 與 V 就是以單個拉丁字母出現的）。

### 另一處訂正

本檔 glossary 原寫「死亡手機畫面的『張狂男』為字形誤讀」——**該判斷是錯的**。
第二季最終話 ep417 中，開票者（鴿子）對光男自稱「身為张狂男」，
可見**莊狂男／张狂男是真實的身分名**，與「光男」並列。第三季遇到不要改掉。
