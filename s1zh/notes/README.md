# HELLPER 第一季 简体中文参照资料（漫网《地狱尽头》）

供翻译第三季韩文生肉时核对**简体版用字**。与 `s1ref/`（台版繁体）是同一季的两套官方/汉化译本。

## 数据来源

- 站点：https://www.manwang.net/book/522343 ，标题《地狱尽头》，共 189 话：预告（ep000）＋ 第 1～188 话。
  第 188 话「AND」台版没有。**第 97 话「北海巨妖」在站点上损坏**（页面只返回跳转页，多种 UA 均无效，2026-09-14），已从用户提供的《地-狱-尽-头-第081-100话.pdf》合集截出补齐（42 页 jpeg，PDF 页 702–743）。
- 抓取时间：2026-09-14，在 aro-81（国内 IP）上用 Playwright 渲染页面取图。图片 690px 宽 webp，共 188 话 / 510M。
- OCR：RapidOCR（onnxruntime），文本在 `../ocr/epNNN.txt`，格式与 `s1ref/ocr` 相同（首行 `# EPNNN 标题`，图与图之间 `---`）。
- 成品：aro-81 `~/hellper-s1/pdf/NNN.pdf`（每话一个 PDF，一图一页，000=预告，与 `上传/第一季/` 同样的命名），188 个 / 744M，用户 rsync 后存百度网盘。
  工程原件仍在 aro-81 的 `~/hellper-s1/`（`tools/fetch.py`、`tools/ocr_all.py`、`img/`、`ocr/`）。

## 使用边界

抓下来的是汉化译本，用途只有一个：**核对专有名词与用字**。不要把它的句子搬进 `zh.tsv`。
