# 批次整理说明（给分批通读的会话／子代理）

目标：把漫网《地狱尽头》（HELLPER 第一季简体汉化）的 OCR 文本读一遍，产出 `batch_AAA-BBB.md`，
格式与 `batch_000-019.md` 完全一致。这些批次文件最后会合并成 `glossary.md` / `episodes.md` / `名词对齐清单.md`。

## 输入
- `../ocr/epNNN.txt`：话号 NNN = 漫网第 N 话（000 = 预告）。首行 `# EPNNN 标题`，图与图之间以 `---` 分隔。
- 台版对照：`../../s1ref/ocr/ep(N+1).txt`（台版文件序号 = 漫网话号 + 1）。台版名册在 `../../s1ref/notes/glossary.md`。
- 现行译名总表：`../../翻译知识库.md`（第三季翻译正在用的名字）。

## 读法
1. 先用下面的脚本把一批压成紧凑格式再读（每张图一行，`|` 连接），比读原始文件省一半 token：
   ```bash
   cd s1zh && python3 - <<'EOF'
   import glob
   for f in sorted(glob.glob('ocr/ep0[2-3][0-9].txt')):   # 改成本批次范围
       s=open(f,encoding='utf-8').read(); head,*blocks=s.split('\n---\n')
       print('#####',head.strip())
       for b in blocks:
           b=' | '.join(x.strip() for x in b.split('\n') if x.strip())
           if b: print(b)
   EOF
   ```
2. 每话开头那段「本作品纯属虚构…」是汉化组的免责声明，跳过。`HELLP3R`、`KILLBEROS`、`待续` 是画面固定元素。
3. OCR 会把同一气泡的行和相邻气泡打散、错序，读的时候按语义拼；拿不准的字可以对照台版同一话。

## 输出（写入 `batch_AAA-BBB.md`）
1. **逐话一句**：`- epNNN 标题：谁做了什么、导致什么。` 不写「本话精彩」这种空话。有资料卡（年龄/身分/统称）的角色在该话一并列出。
2. **名词登记**：按阵营分表，列 简体版用字｜年龄｜身分｜统称｜首见话号｜台版对照。角色资料卡是最可靠来源，标「卡」。
   - 同一阵营的名字摆在一起看一遍，留意成套的名字（如 War+身体部位、L·O·V·E）。
   - 疑似人名先往三国／西游／水浒上想，别当成音译。
3. **用字浮动**：同一名词在本批次里出现的不同写法（如 基尔倍罗斯／基尔贝罗斯），各自的话号与次数。
4. **篇章标记**：画面上出现的 `PROLOGUE END`、`SEASON 1`、`MADMAN`、`END`、`epilogue` 等原样记录，标话号。
5. **与现有术语表的冲突／待决**：本批次里与 `翻译知识库.md` 或 `s1ref/notes/glossary.md` 不一致的，一条一句，注明依据话号。

只做登记，不做裁决——哪个译名该采用由用户最后拍板。
