## 主线一句话

**第二季是前传，不是续集**——终点在张光男死亡之前，所以第一季的死界／阴间全线均未登场。

孤儿院里被捡回的失忆少年成为张光男 → 中学篇建立起 KBRS 的班底 → 药物（Holy Juice）与
邱蛇会、KASA、影子政府〈黑矿〉层层缠绕 → 鳄鱼岛决战后遇见任德成，接下**围栏计划
HUMAN FENCE** → 统一加纳市十大战斗部落，KBRS 成为「守护部落」→ 最终话由**鸽子**
（＝开票者·张狂男的临死备份）交代戈尔戈、White Juice、战争手的全部底层设定，接回第一季。
